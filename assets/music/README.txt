Taruh file lagu di folder ini (format .mp3 paling aman untuk semua HP).

Contoh: assets/music/our-song.mp3

Lalu buka config.js dan isi:
  music: {
    src: "./assets/music/our-song.mp3",
    title: "our song",
    volume: 0.25
  },

Tips: pakai nama file tanpa spasi, dan usahakan ukurannya di bawah 8 MB.
